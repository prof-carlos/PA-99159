PROJETO PRÁTICO • BACKEND

Desenvolvimento de API REST para a NexusStore

Objetivo: Aplicar os conceitos de rotas, verbos HTTP e manipulação de dados (CRUD) construindo uma API comercial.

1. O Cenário (Demanda Real)

Contexto do Cliente

A NexusStore, uma rede regional de lojas de departamentos, está passando por um processo de transformação digital. Até então, o controle de clientes, colaboradores e estoque era feito de forma isolada em planilhas eletrônicas, gerando perda de dados e furos de estoque.

Você foi contratado(a) como Software Engineer para desenvolver a API Core do novo sistema ERP deles. Essa API será a base para o funcionamento do aplicativo mobile dos vendedores e do painel web da diretoria. Sua missão nesta etapa é criar os endpoints iniciais para gerenciar o ecossistema da empresa.

3. Operações Obrigatórias (CRUD)

Para as três rotas base (/clientes, /funcionarios e /produtos), você deve obrigatoriamente implementar as seguintes ações utilizando as boas práticas dos métodos HTTP:

  • GET - Listar todos os registros da entidade.
  • GET por ID - Buscar um único registro através de um identificador único (ex: /clientes/:id).
  • POST - Cadastrar um novo registro.
  • PUT - Atualizar todos os dados de um registro existente através do ID.
  • DELETE - Remover um registro do sistema através do ID.
